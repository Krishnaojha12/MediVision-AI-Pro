# 🏥 MediVision AI Pro

## 📌 Overview

MediVision AI Pro is an AI Powered Healthcare Analytics System developed using Python, Streamlit and Machine Learning.

It helps hospitals analyze patient data, visualize healthcare information, predict billing amounts and generate professional PDF patient reports.

---

## 🚀 Features

- 📂 Upload CSV and Excel datasets
- 🧹 Data Cleaning and Preprocessing
- 📊 Interactive Dashboard
- 🤖 Machine Learning Prediction
- 📄 Automated Patient PDF Report
- 📈 Healthcare Data Analysis

---

## 🛠 Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Plotly
- ReportLab
- OpenPyXL
